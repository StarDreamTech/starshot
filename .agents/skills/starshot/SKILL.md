# 星镜 Starshot

中文、星空主题、本地优先的独立截图、标注、桌面贴图与图片美化软件，Rust / Tauri 2 / Vue 3 / TypeScript；macOS 与 Windows 同等重要。星笺 Starclip 是独立产品，不重复开发星伴。

本 skill 是所有项目对话共享的知识库入口。工作前读取，完成有结论的工作后按 [AGENTS.md](../../../AGENTS.md#项目知识库维护) 主动维护；用户说「更新skill」须回顾整个可访问对话、比对已有记录。入口仅保留概览、关键约定和索引，具体实现与历史证据在下列资料维护。

## 关键约定

- 星镜专注截图及相关编辑，当前会话最近6张足够；长期剪贴板历史由星笺负责，不列为星镜缺口。无需可编辑项目文件导入导出；保留正常图片导入、PNG/JPEG导出及本机会话恢复点。
- 默认不截图、不读或监听剪贴板、不上传图片；显式复制才写剪贴板。图片/编辑平时仅内存，手动、退出前选择备份及安装更新才保存完整本机会话；启动不自动恢复。
- 轻量截图优先：选区旁标注、复制、保存、贴图，主动「更多编辑」才进入完整编辑器；取消截图保留会话并保持主窗收起。已有选区右键重选、无选区再右键退出。Tab逐级扩大、Shift+Tab返回的内部面板预选是用户最终决定，替代此前暂缓意见。
- 长截图当前工作区支持竖向向下/横向向右拼接，主动开始自动滚动或手动补采，Esc/空格暂停；累计预览蓝框显示最近一屏，失败保留结果。反向滚轮只校正自动输入，不是反向拼接；尚未替换日用版，双平台生产采集仍待原生验收，见[长截图说明](../../../docs/scroll-capture.md)。辅助线H显隐；C复制原像素色值、轻按Shift切格式、Alt临时放大镜。F1/F3只是可填入并保存的预设，不自动覆盖用户快捷键。
- 贴图双击关闭、右键菜单、原生悬浮提示；焦点光圈默认开启且可关闭，活跃蓝色、失焦灰色，只影响预览、不写入输出图。设置齿轮与主题调色盘独立，设置按五个标签分组；分享内容先预览再显式复制，托盘动作显示真实状态和操作结果。
- 平台特性按目标编译/打包：Rust cfg、Cargo target依赖及Tauri平台资源；共享编辑器保留一套。Windows自研UIA/helper和原生验收交付必须保留完整源码，不能仅有DLL。
- 源码实现、自动检查、浏览器模拟、平台构建及原生实测分开记录；窗口几何/像素启发式不能称为系统控件语义识别。控件查询仅读角色/几何关系，不读取目标界面文字；失败可回退窗口/像素候选或手动框选。
- 占用检测仅确认当前能否注册；macOS独占冲突可识别，非独占共享和系统保留键不保证全部识别，也不报告占用软件名。保存失败保留草稿并报告实际绑定/回滚错误。
- 用户不希望反复承担Windows测试转交；v3交付已接回并收尾，未覆盖场景保留为限制，不再默认要求第四轮转发。双平台目标不等于两平台所有原生验收均已通过。
- 只用原创demo或固定生成像素测试，不为测试捕获真实桌面，不读真实剪贴板；截图和私有日志只保存在Git忽略的`artifacts/`，不将真实图片、凭据或日志入Git。保存/复制/导出按真实结果反馈；浏览器下载只能报告请求已发起。
- 保留用户和其他对话的工作区改动。提交说明中文；无提交、推送、发布、安装的默认授权，知识库维护不扩展权限。既有授权按本次具体范围判断，不重复询问已明确授权的动作。
- 本机更新使用固定日用入口；替换前必须通过应用手动备份当前会话并核实长度/SHA、归档核验旧应用，再退出替换，不能用旧程序归档代替图片会话备份。系统身份验证由用户本人完成；权限以新进程预检判断，不能只看系统开关。
