# 星镜产品范围

## 已确认方向

2026-10-26用户要求在星笺之外再开发一款截图软件，参考Snipaste，必须考虑区域预判与图片边框、背景等编辑亮点；明确接受「星镜 Starshot」名称，并选择macOS与Windows同等重要。本次不开发重复的星伴，不删除星笺已有能力。

2026-10-27用户结合竞品录屏进一步确认：星镜不做星伴；优先保证截图流畅、选框准确和就地操作。选区确定后用贴近选区的工具条标注、复制、保存或贴图，仅主动选择「更多编辑」时进入完整编辑页。

2026-10-29用户以Snipaste贴图参考图确认增加默认开启、可关闭的焦点光圈，区分当前活跃贴图和失焦贴图。工作区采用活跃蓝色柔光、失焦灰色阴影，全局开关在本机记忆，可从设置页或贴图右键菜单修改；光圈仅影响桌面预览。

同日用户指出悬浮提示有助于发现功能。工作区在贴图图片区、工具栏和菜单补齐操作与快捷键说明，对穿透等操作说明恢复方法，对光圈说明实际设置入口；沿用原生悬浮提示。双击仍固定关闭，尚无鼠标行为配置项。

同日用户最终确认补齐内部面板预选，以Tab扩大范围。macOS已实现鼠标命中节点的有效父级路径，并在只命中大容器或未取得内部候选时局部查找子元素；默认较小有效控件/面板，Tab逐级外扩，Shift+Tab返回。不是针对ChatGPT的应用名或固定坐标特判；应用须提供有效辅助功能几何，失败仍可选窗口或手动框选。此决定替代此前暂缓意见，竞品表现仅为用户反馈。

2026-11-05用户要求借鉴Snipaste快捷键、右键重选和就地提示，并避免截图时屏幕四角触发macOS热角。工作区已补齐下述交互；F1/F3作为可选预设，保存后才替换当前全局绑定，不自动改动已有配置。macOS保护仅在普通截图覆盖层期间生效，不修改用户热角偏好；旧系统不能保证抑制所有热角动作。

同日用户要求便于修改快捷键、识别占用，并区分设置与快速主题入口。工作区已增加按键录入和实际试注册检测；设置改用齿轮，另设调色盘图标切换主题，配置分为外观、快捷键、通用、更新与恢复、关于五个标签。修改快捷键仍须保存生效，保存失败保留输入草稿和已生效快捷键提示。Mac可识别独占注册冲突，非独占共享与系统保留组合不保证全部可检测；「当前可注册」不代表没有其他监听者，也不能识别占用的软件名称。

2026-11-10用户要求分享图片和文案复制前先给出预览，并修复「开始截图」悬浮时文字与背景接近的问题。已有分享功能改为先展开文案或原创产品图，再显式确认复制；图片保存也从预览进入。主按钮共用hover规则保持主题强调背景与配套文字颜色，修复同类按钮的覆盖问题。

同日用户提供Snipaste菜单栏图，要求完善星镜托盘交互。工作区已将常用截图/贴图放前面、管理操作收进子菜单，并补齐贴图显隐/数量、快捷键暂停、共享光圈、偏好设置、检查更新、操作说明和关于；根据真实状态置灰。快捷键暂停仅本次运行，真正释放两项注册，保存配置保持暂停，恢复冲突回滚并显示错误。分享和托盘这批修改已有macOS构建及模拟IPC证据，尚未安装或发行，原生托盘与Windows验收另记。

默认中文、星空主题、本地优先；动作使用「开始截图」「导入图片」「贴到桌面」「导出图片」等直观名称。无账号、云后端、遥测和启动联网。主界面五套外观继承系列偏好，图片背景独立于界面主题。

2026-10-26用户进一步确认产品分工：星镜专注截图及相关标注、贴图、美化，当前会话最近6张图片满足需要；长期剪贴板历史由星笺负责。持久截图历史不作为星镜的功能缺口或待办。现有手动备份、更新前会话恢复用于保护编辑进度。用户随后明确无需新增可迁移项目文件导入/导出，保留正常图片导入和PNG/JPEG导出。

## 资源限制与行为

- 前端导入不超过32MB，最长边16384、2400万像素；原生截图每屏4000万像素，最多8屏，合计8000万像素。
- 长截图选区最小64×64，每边最多16384、4000万像素、最多100屏；PNG编码还须≤64MiB，超限拒绝新增屏并保留此前结果。需保留至少三分之一重叠（推荐半屏）。先采集再标注；竖向向下或横向向右拼接，追加成功后锁定方向。自动滚动须主动开始；暂停时结束当前采集，不再调度下一次，完成/取消/关闭后不采集。反向滚轮仅校正自动输入，不表示支持向上/向左拼接。重复纹理/动效/复杂悬浮页眉可能导致拒绝或误拼，应检查预览；画面不变不等于已证明到底。
- 输出最长边16384、最多6400万像素；原生解码数据上限64MB。2×会将总像素变为4倍，超限明确拒绝。浏览器Canvas实际分配能力还受设备内存限制。
- 最近会话最多6张原图，原图合计4800万像素；超限按最旧顺序移除。背景图、编辑快照与渲染缓冲另占内存，此预算不是进程总内存硬上限。
- 图片不自动保存；关闭应用会失去未导出且未备份的会话。手动恢复点与更新前恢复点可重建原图、标注、裁剪、美化、背景和主题，不包含撤销历史或桌面贴图，启动不自动恢复。
- 全局贴图快捷键贴最近截图原图；美化后的图片用编辑器「贴到桌面」。快捷键可在设置录入或编辑，占用检测只确认此刻能否注册，保存仍需再次登记；Mac独占冲突可识别，非独占共享及系统保留组合不保证全部可检测。「当前可注册」不代表没有其他监听者，不能报告占用的软件。注册失败尝试恢复原绑定，若系统恢复失败会明确报错；失败草稿保留供修改，不作为已生效提示。
- 关闭主窗口隐藏到托盘，不等于退出；无会话、无待处理操作时经前后端握手释放主WebView，呼出时重建。有图片/编辑进度时保留窗口。真正退出前未备份会话提供备份并退出、直接退出、取消；退出后所有贴图与内存会话清除，已创建的本地恢复点保留。
- 截图失败保留原有编辑；取消截图（叉号、Esc、无选区时右键或系统关闭）只关闭截图覆盖层，不弹出主窗口，从主窗口进入截图也遵循此规则，原有图片与编辑会话保留。已有选区时右键先清除选区、标注与该次撤销历史，回到悬浮预选，再次右键才退出；此规则取代此前右键直接取消。快速复制/保存/贴图成功后关闭选区，不唤起大编辑器；主动“更多编辑”才进入编辑器。截图启动失败仍显示错误；保存取消或操作失败保留选区和标注。截图预览模式始终使用原创素材。
- 主编辑器和就地标注预览按显示像素绘制，每张预览画布最多4MP；导出仍用原图像素。鼠标移动按rAF合并，放大镜只在可见时读取小画布。性能数据仅表示对应原创图、环境和测量条件，见验证记录。

### 打码与资源边界

- 识别只由用户按钮触发，输入为当前裁剪范围内、已合成标注/贴纸的图片像素；不自动截图、不读取剪贴板、不上传、不保存识别文本。
- 本地OCR长边最多4096，候选返回原图坐标。过小文字/复杂背景/长图可能漏识别，可裁剪重试或手工遮盖；「未找到候选」不代表图片无敏感信息。规则按整行加边距，避免猜字符位置而遗漏部分凭据。
- 识别候选与画布选择框仅用于预览；确认后变为可撤销的实心黑色遮盖，后添加贴纸/马赛克不能盖在遮盖之上。PNG/JPEG成图为扁平像素；本机恢复点仍含完整原图，不能当作脱敏文件分享。
- 单张贴纸仅内嵌PNG、最多2MiB/200万像素，当前会话实例合计8MiB/800万像素；恢复前预解码并校验。缓存随可达编辑/撤销状态清理，撤销/背景/渲染内存仍另计。
- 普通图片及编辑仍只留在内存；主题、自定义配色、截图延时、导出偏好和不含图片的美化预设可持久保存。自启动状态读取系统实际注册项；系统登录策略仍可能阻止启动。
- 恢复点及关联旧应用可由用户选择删除，无默认自动清理。统计失败显示未知并保留恢复入口；删除遇符号链接等异常会拒绝。

### 保留分工与后续

不新增持久截图历史或可迁移项目文件导入导出；养成系统、长期剪贴板历史、链接域名分类属于星笺。用户侧CLI/MCP/Skill仍是后置候选，未开通自动读取图片、恢复点或截图的接口。Windows安装/卸载证据已有，WinGet仍需单独生成并验证清单、提交官方审核；不将Homebrew接入当作Windows已上架。系统控件识别、长截图增强与跨屏连续选区继续保留在上表。
