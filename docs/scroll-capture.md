# 长截图（2026-11-10工作区）

用户要求实现长截图，并提供QQ界面参考。采用方向切换、自动滚动入口、累计图片预览及当前屏蓝框；参考图的版本和实现未核实，不将其算法或跨平台表现作为星镜证据，不将用户图片加入仓库。

## 操作

1. 正常截图并框选可滚动内容；选区中心应在可滚动区域内。已有标注时先撤销标注，长截图完成后再编辑。
2. 点击选区工具条的「滚动长截图」，首屏保留在内存。选择竖向（向下）或横向（向右）；成功追加后锁定方向。
3. 点击「开始自动滚动」，或自行滚动后点击「采集下一屏」。手动采集应保留至少三分之一重叠，推荐半屏。
4. 自动模式用按钮、Esc或空格暂停；快捷键在控制窗有焦点时生效，临时隐藏期间需等控制窗恢复。在途的一次采集结束后不再调度下一次。暂停后可补采、复制、保存、贴图或进入更多编辑。再次Esc可取消整个会话。
5. 系统或滚轮增强软件使输入方向相反时，暂停后勾选「反向滚轮」重试。此选项只校正本次会话的自动输入，不是向上/向左拼接。

控制窗默认380×540逻辑像素，尽量放在选区旁，受原显示器可用空间约束；采集时暂时隐藏，之后恢复。预览按可用空间等比缩放，蓝框表示最近追加的一屏，尺寸和屏数按后端结果显示；这些装饰不进入输出。

## 实现与保护

- `src/components/CaptureOverlay.vue`串行调用`append_scroll_capture`，显式传入`automatic`、`direction`和`reverse`；默认不自动开始。成功后间隔650ms再调度，失败、重复画面、100屏、暂停或卸载都会停止。暂停不销毁已拼接结果，保存取消仍可继续。
- `src-tauri/src/desktop.rs`保存首屏显示器、选区及其中心处最前窗口的几何/身份；macOS核对PID与几何，Windows额外核对原生句柄及进程身份。自动输入前及稳定采样期间复核原窗口；显示器移除、位置/缩放/尺寸变化和目标被遮挡时停止。capture窗口ACL、唯一label及operation锁继续限制当前会话；前端不提供任意PID、窗口句柄或屏幕坐标。
- `desktop/scroll_input.rs`按目标平台编译。macOS使用CoreGraphics像素滚动、非弹窗的事件权限检查和原窗口复核；事件指向选区中心，不主动移动鼠标。Windows向命中的原生子窗口发送有250ms超时的`WM_MOUSEWHEEL`/`WM_MOUSEHWHEEL`，检查根HWND及原始进程身份，并在物理DPI上下文中打包有符号坐标；坐标超出消息范围时拒绝。两平台都不主动申请权限或更改滚轮设置。
- 自动滚动后等待400ms，再每150ms采样；两次连续相近画面才拼接，最多8轮，持续变化则停止并保留旧结果。这是有界像素稳定启发式，不能证明所有懒加载均已完成或识别页面语义。手动模式仍是单次显式采集。
- `src-tauri/src/scrolling.rs`复用重叠搜索与密集验证；横向帧旋转90°进入同一拼接管线，预览与所有完成出口再还原方向，不缩放成图。未变化不追加；匹配失败保留原像素、上一屏锚点和屏数。横向失败提示改为向左滚回。
- 上限仍为100屏、单边16384像素、总计4000万像素及PNG编码64MiB；分配/编码校验在提交新结果前完成。普通图片仍仅在内存；显式保存/复制等复用既有真实结果出口，不引入启动或后台常驻采集。

## 验证与限制

纯算法覆盖纵向、横向原始像素、重复帧、反向拒绝、简单固定头尾、动态区域拒绝及资源上限。浏览器脚本`tests/browser-capture-regression.mjs`使用原创像素和模拟IPC，检查方向锁定、预览蓝框、串行自动推进、在途暂停、失败停止和完成出口；不代表原生屏幕采集通过。

macOS输入夹具仅由`tests/macos-scroll-fixture.swift`生成原创AppKit窗口，`src-tauri/tests/macos-scroll-smoke.rs`核对所启动PID及原窗口几何，调用生产滚动函数并读取该夹具报告的滚动偏移。它不捕获真实屏幕、不读剪贴板、不请求权限，不覆盖生产截图/拼接全流程。本机轮次使用`STARSHOT_SCROLL_REVERSE=1`通过；默认方向和其他系统/滚轮设置须另验。

```sh
xcrun swiftc tests/macos-scroll-fixture.swift -o artifacts/macos-scroll-fixture
STARSHOT_SCROLL_FIXTURE="$PWD/artifacts/macos-scroll-fixture" STARSHOT_SCROLL_REVERSE=1 \
  cargo test --locked --manifest-path src-tauri/Cargo.toml --test macos-scroll-smoke \
  targeted_scroll_moves_only_original_fixture_without_capture -- --ignored --nocapture
```

真实跨应用自动滚动/采集、Windows新构建与原生输入、复杂固定层/动态页面、长时间稳定性均未完成。窗口消息或系统事件不保证每个应用接受；不响应时停止并提供手动补采。画面未变化可能是到底、加载延迟、目标不支持输入或方向问题，不声称已经证明到底。当前只拼向下/向右，反向拼接仍待实现。每轮检查与打包结果以[验证记录](verification.md)为准；本轮不自动安装或发行。
